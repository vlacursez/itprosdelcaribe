# ITPros del Caribe - Versión 4

Sitio estático de presentación para soporte técnico y consultoría de TI en Barranquilla y la Región Caribe de Colombia.

Esta versión conserva el sitio publicado en la versión 3 y añade las insignias CertiProf ISO/IEC 42001 Internal Auditor (I42001IA) y AI Agent Manager (AIAM), una sección de certificaciones y dos servicios relacionados con auditoría interna de sistemas de gestión de IA y gestión de agentes de IA.

El carrusel presenta nombres como referencia tecnológica; no indica afiliación, certificación ni patrocinio. Para utilizar logotipos oficiales se deben confirmar los permisos correspondientes y emplear archivos de marca autorizados.

## Vista local

Abre `index.html` en un navegador. La página no necesita instalar dependencias ni compilarse.

## Publicación en GitHub Pages

El flujo en `.github/workflows/pages.yml` publica los archivos del repositorio cuando se incorporan a la rama `main`. En el repositorio, habilita GitHub Pages usando GitHub Actions si aún no está seleccionado.

## Contacto y contenido

La información de contacto se tomó de la propuesta comercial disponible al preparar el sitio. Confirma que el teléfono y el correo continúan vigentes antes de publicar. El contenido del sitio resume los servicios descritos en el catálogo y la propuesta; no incluye promesas de cobertura horaria ni tiempos de respuesta.

Las palabras clave se integraron como lenguaje natural en títulos y descripciones. Los archivos de investigación encontrados corresponden al periodo 2020–2021 y no se presentan como datos vigentes.

Las fotos de Pexels se guardaron en `assets/` en versiones reducidas y se asignaron a las categorías de infraestructura, conectividad, consultoría, soporte, mantenimiento y monitoreo técnico. La lista de autores y fuentes está en [PHOTO-CREDITS.md](PHOTO-CREDITS.md) y en los créditos al pie de la página.
